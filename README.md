# Intune - Device Compliance Policy

## What I did
- Created a compliance policy in Microsoft Intune
- Required: Minimum OS version, Device encryption and Password
- Assigned the policy to a test group
- Checked device status: Compliant / Non-Compliant

## Tools
Microsoft Intune, Entra ID, Microsoft 365

## Result
When a device is not compliant, access is blocked and user receives a remediation message.
